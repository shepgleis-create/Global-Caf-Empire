# Global Café Empire — Godot 4 (development)
This repository is dedicated to the original Global Café Empire game, **not** Motor Dynasty, Studio Empire, or the older JavaScript browser preview.

## Direction
Native Godot 4.x, 3D world rendering, portrait-first mobile UI, deterministic weekly café economics, double-entry accounting, save compatibility, 64 planned city markets, and original independently authored assets.

## Current state
The initial Godot v0.1 source package is under active migration into this repository. The old publicly hosted HTML preview is a separate prototype and is **not** the 3D Godot game. This repository should not be linked to Vercel as a deployed Godot game until a real export exists and passes smoke tests.

## Evidence standards
Only screenshots captured from the running Godot scene may be shown as gameplay. Concept artwork, reference screenshots, or generated images cannot substitute for live build evidence. Engine and iPhone tests must be reported independently.

## Run
Use Godot 4.4+ on Linux/macOS/Windows. Once all project files have been committed, open `project.godot` and run the game. An HTML preview is not a native export.

## Ownership / originality
Game code and geometry are independently produced. Reference screenshots are only a gameplay-depth and UX brief; no copied screenshots or asset extractions are included.
